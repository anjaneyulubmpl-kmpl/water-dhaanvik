# Water Dhaanvik

Android Expo/React Native app for estimating groundwater availability at a selected map location.

## Features
- GPS current location
- Interactive map
- Tap the map to select a location
- Low / Medium / High groundwater estimate
- Clear estimate-only disclaimer

## Important
The included estimator is demonstration logic only. It is **not** a groundwater detector and should not be used alone for drilling decisions. Replace the demo logic with validated hydrogeological, geological, groundwater, and/or ERT data before real-world use.

## Run
```bash
npm install
npx expo start
```
